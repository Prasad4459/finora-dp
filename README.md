# Money OS Hub

I want to build a modern Personal Finance Management web application called MoneyOS.

The application should have a clean, premium UI inspired by Notion, Stripe Dashboard, and Apple.

Tech Stack:

- React

- TypeScript

- Tailwind CSS

- Supabase backend

- PostgreSQL database

- Supabase Authentication

The application should support both desktop and mobile.

Do NOT build everything at once.

Create the project architecture only.

Include:

- Authentication

- Sidebar

- Dashboard

- Accounts

- Income

- Expenses

- Assets

- Liabilities

- Settings

Create reusable components.

Use cards, tables, charts placeholders, and responsive layouts.

Use a modern color palette with light and dark mode support.
